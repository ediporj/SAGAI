# Contribuindo com o SAGAI

Obrigado pelo interesse! Este documento explica como contribuir.

## Como começar

1. Faça um fork do repositório
2. Clone o fork localmente
3. Abra o projeto no Godot 4.6
4. Crie uma branch para sua contribuição: `git checkout -b minha-feature`

## O que aceito

- Novos locais, tarefas ou eventos narrativos
- Novos itens ou NPCs
- Melhorias de UI/UX e acessibilidade
- Correções de bug
- Traduções (o jogo está em português, mas inglês é bem-vindo)
- Otimizações de performance

## Código

- Use GDScript (não C#)
- Siga o estilo já presente nos arquivos — snake_case para variáveis e funções, UPPER_CASE para constantes
- Evite dependências externas
- Prefira editar scripts existentes a criar novos, a menos que faça sentido estrutural

## Pull Requests

- Um PR por feature ou fix
- Descreva o que mudou e por quê
- Se adicionou uma tarefa ou evento, explique os efeitos nos atributos

## Issues

Use as labels:
- `bug` — algo quebrado
- `enhancement` — sugestão de melhoria
- `content` — novo conteúdo narrativo (tarefas, eventos, NPCs)
- `question` — dúvida sobre o projeto

## Dúvidas

Abra uma issue com a label `question`.
